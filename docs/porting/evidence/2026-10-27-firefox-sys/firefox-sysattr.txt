## blockers
1. PTRACE_ATTACH returns EIO (ptrace attach not usable) -> no live strace.
2. strace from exec traces only the launcher; Firefox does not reach a window
   under it (clone3 error=1 in the trace) -> no scroll-time histogram.
3. /proc/<pid>/stat minflt/majflt are 0 on this kernel -> no fault attribution.
