日期：2026-10-27　镜像：`target/softgl/base.ext2`（lxterminal + mousepad + 软 GL/IM 默认值）
内核：`feat/drm-virtio-gpu`（virtio-gpu DRM，Xorg 依赖 `/dev/dri/card0`）

## 1. 负载与时间线

- 起点（host）`date +%s = 1793111593`（22:33:13 CST）；guest 在脚本初始化完成后打印
  `SOAK60_START guest=1793111602 up=90.05`。
- 负载：Firefox 打开本地页 `file:///home/asterinas/daily/hello.html` 常驻；
  后台 `dd if=/dev/zero of=soak.bin bs=1M count=16 conv=fsync` + `sleep 5`（限速）；
  每 5 分钟开一次 `lxterminal` 与 `mousepad`，20 秒后关闭。
- 每 5 分钟采样一次：`date +%s`、`/proc/uptime`、`free -m`、进程数、
  firefox/lxterminal/mousepad 计数、`dmesg | tail -5`（见 §4 说明）。
- 终点：`SOAK60_DONE guest=1793115443 up=3931.97`；宿主在
  `1793115444`（日志落盘时刻）观测到该行。

## 3. 两端时钟对照（本轮的重点）

| 量 | 值 |
|---|---|
| guest 起止 | 1793111602 → 1793115443 |
| **guest 经过** | **3841 s = 64.02 min** |
| 工作负载理论时长 | 12×300 s + 12×20 s（窗口轮次）+ 少量开销 ≈ 3840 s |
| host 观测 DONE 时刻 | 1793115444（与 guest 打印同秒级） |
| **host 墙钟经过** | **≈3842 s = 64.03 min**（host 起点 1793111593 至 DONE，含启动初始化 9 s） |

**结论：guest `CLOCK_REALTIME` 与宿主墙钟在 64 分钟里只差 1–2 秒（比值 0.9997），
`/proc/uptime` 同步增长（90.05 → 3931.97 s，与 guest date 的增量一致）。
"0.5× 时钟"被彻底否定**——上次是没记墙钟、把一次提前退出的 soak 当成 12 分钟所致
（见 `2026-10-27-clock-half.md` 的 9 组 60 秒测量，比值同样 0.997–1.002）。

## 4. 稳定性判定

| 指标 | 结果 |
|---|---|
| panic | **0**（整段串口内核日志） |
| `allocation failed` | **0** |
| `heap:` 告警 | **0** |
| 进程数 | 30（首样本）→ 31，之后 12 个样本恒为 31，**无漂移** |
| 内存 | 1.08 GB → 1.24 GB，第 5 个样本后进入平台期（Firefox 缓存），无单调泄漏 |
| Firefox | 全程存活，本地页持续驻留（fw=1 全部样本） |
| 窗口开关 | 12 轮 lxterminal/mousepad 开关无崩溃、无残留进程 |

`dmesg(1)` 在该 guest 上没有任何输出（内核日志走串口，宿主持有完整 console），
所以内核侧判定以串口日志为准：上述三个计数都在整段日志上统计。

## 5. 结论与下一步

- 64 分钟、带 Firefox + 窗口churn + 限速同步写的负载下，内核无 panic、无分配失败、
  无 heap 告警、进程/内存稳定；日用稳定性达到可接受水平。
- 时钟问题关闭：两端时钟一致，之前 0.5× 是测量口径错误。
