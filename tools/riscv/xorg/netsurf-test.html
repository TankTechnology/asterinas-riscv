The NetSurf logo, decoded by libpng.

Milestone

This page is rendered by NetSurf 3.9, a lightweight HTML/CSS browser, cross-compiled for riscv64 and running on the Asterinas RISC-V framebuffer desktop (Xorg + matchbox-wm + GTK2).

What this page exercises

  • CSS colour styling — author stylesheet colours (cream body, blue headings, grey table headers).
  • HTML tables — collapsed borders, header shading.
  • Block-level layout — headings, paragraphs, lists, quotes.
  • Image decoding — the PNG logo at right, fetched by <img> and decoded via libpng.

NetSurf is a small, fast web browser. On Asterinas it is a mostly-static binary — GTK2, Pango, Cairo, libcss/libdom/libhubbub and libcurl are all linked statically; only glibc is dynamic.
